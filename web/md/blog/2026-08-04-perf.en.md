44 documents × 2 languages × 2 versions — build time reduced from 16 seconds to ~1.4s (full) / ~0.85s (incremental). A **19x speedup**.

## The Fix

### Built-in Queries

Blog sorting, pagination, and tag aggregation moved from Python plugins to native C++. The `on_data_query` hook no longer spawns any subprocesses.

### Full Parallel Rendering

All page types use `run_parallel` worker pools. Multi-locale rendering runs zh-CN and en simultaneously.

### Component System

- **Preloaded components**: All HTML loaded at startup, no per-page filesystem search
- **Map precompilation**: JSON sections → FlatCmd instructions, direct buffer output
- **Output pipeline fusion**: `finalize_html` merges i18n + minify + webp + fingerprint
- **Shortcode dedup inline**: `<style>` deduplication merged into expansion pass

### Async I/O

`std::async` runs feeds, sitemap, and robots in parallel with page rendering — saving ~0.3s.

### Asset Copy

Windows `robocopy` replaces `fs::copy`: 130+ files from ~6s to ~0.3s.

### Incremental Builds

Three-tier signatures active for all builds, not just `serve -w`. All page types support skip. Stale HTML auto-cleaned.

### JS Module Fixes

- ES module `import` statements get `?v=` fingerprints at build time
- `window.__cdocs_asset_root` injected by C++ for reliable asset path resolution
- Service Worker cache version bumped to prevent stale module caching

## Final Performance

| Scenario | Time |
|----------|------|
| Clean build (with assets) | ~1.4s |
| Full render (assets cached) | ~1.2s |
| Incremental (no changes) | ~0.85s |
| Incremental (1 file changed) | ~0.9s |
